README.md remains the user-facing quick start. Keep detailed procedures here
instead of maintaining copies in multiple agent files.

Distinguish implemented behavior, dated observations, hypotheses, and pending
checks. Link to code/evidence and record dates; do not turn one board's observation
into a guarantee for all modems, carriers, or hosts.
